## ⭐ Proyecto principal

## ⭐ POS System

Sistema de Punto de Venta (POS) desarrollado con una arquitectura moderna Full Stack, diseñado como un proyecto de nivel profesional para simular el desarrollo de software utilizado en empresas.

El objetivo del proyecto es aplicar arquitectura, seguridad, bases de datos, documentación, control de versiones y desarrollo de funcionalidades completas de frontend y backend.

### Funcionalidades

* Autenticación con JWT
* Inicio y cierre de sesión
* Control de usuarios y roles
* Gestión de productos y categorías
* Gestión de clientes y proveedores
* Control de inventario
* Registro de ventas
* Activación y desactivación de registros
* Validaciones y manejo centralizado de errores
* API REST documentada
* Migraciones de base de datos
* Entorno de desarrollo con Docker
